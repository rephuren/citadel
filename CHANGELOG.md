# История изменений

## Не выпущено

### Добавлено
- HTTP: отдельный поток GET для уведомлений сервера (`tools/list_changed` обновляет каталог шлюза без запроса), до трёх переподключений при обрыве, ответ 405 допустим, запросы сервера в потоке отклоняются, размер одного события SSE ограничен (#8)
- серверы по streamable HTTP: поле `url` (и `headers`) вместо `command`; только `https` (`http` для localhost), без учётных данных в адресе, без редиректов, лимит размера ответа и таймауты как у stdio; ответ JSON или SSE; закрепление, карантин определений и taint работают так же, как для stdio (#4)
- общий базовый класс транспорта `BaseUpstream`
- `docs/threat-model.md`: границы доверия, таблица «угроза → слой → остаточный риск», чего шлюз не умеет, рекомендуемая конфигурация (#5)

## 0.1.0

### Добавлено
- шлюз MCP по stdio: пространства имён `сервер__инструмент`, политики (маски имён, ограничения аргументов, лимиты), подтверждения человеком, журнал аудита
- очистка определений и результатов от невидимых символов, скрытие опасных инструментов правилами basilisk, закрепление определений (`pin`) и защита от подмены (rug pull)
- taint tracking: метки `private`, `untrusted`, `sink`, режимы `log`, `trifecta`, `strict`, поиск прямого перетекания данных
- полигон из учебных уязвимых серверов и бенчмарк «атака × защита» с «послушным» агентом: 9 атак, 7 обычных задач, 6 уровней защиты
- дашборд по журналу аудита (`citadel dashboard`), справочник по конфигурации
- 50 тестов, CI на Node 20, 22 и 24, ноль зависимостей во время работы
